# ohos/ — OpenHarmony Native Shell

**Overview:** Thin OHOS native layer hosting Flutter engine. ArkUI + MethodChannel bridge.

## STRUCTURE

```
ohos/
├── AppScope/                        # App-level config (bundleName, icon, label)
├── entry/                           # Single HAP entry module
│   ├── src/main/ets/
│   │   ├── entryability/            # FlutterAbility (not UIAbility)
│   │   ├── pages/                   # Single page: Index.ets (FlutterPage host)
│   │   └── plugins/                 # MethodChannel bridge + generated registrant
│   ├── src/main/resources/          # Resources (strings, images, rawfile)
│   ├── src/ohosTest/                # Hypium test scaffold (1 trivial test)
│   ├── build-profile.json5          # Stage mode, arm64-v8a only
│   ├── hvigorfile.ts                # HAP build config
│   └── oh-package.json5
├── hvigor/                          # Hvigor tool config
├── hvigorconfig.ts                  # Custom: injects git metadata into DART_DEFINES
├── hvigorfile.ts                    # Uses flutterHvigorPlugin
└── oh-package.json5
```

## WHERE TO LOOK

| Task | Location | Notes |
|------|----------|-------|
| App entry | `entry/src/main/ets/entryability/EntryAbility.ets` | FlutterAbility, engine setup |
| OHOS↔Flutter bridge | `entry/src/main/ets/plugins/HarmonyChannel.ets` | MethodChannel handler |
| Add new plugin | `entry/src/main/ets/plugins/GeneratedPluginRegistrant.ets` | Auto-generated, **don't edit** |
| Change resources | `entry/src/main/resources/` | Strings, media, rawfile, profiles |
| Build config | `entry/build-profile.json5` (committed) + `../build-profile.json5` (gitignored) | Arm64-v8a only |
| Test scaffold | `entry/src/ohosTest/` | Hypium, 1 trivial test |

## CONVENTIONS

- **FlutterAbility** instead of UIAbility (standard for Flutter-OHOS)
- **Single-page shell**: only `pages/Index` in main_pages.json (Flutter handles routing)
- **arm64-v8a only**: x86/x86_64 native libs explicitly excluded
- **Stage model**: `apiType: stageMode`
- **MethodChannel** for OHOS↔Flutter communication (continuation, window state, font weight)
- **Rawfile** for Flutter assets (flutter_assets/, libapp.so, libflutter.so)

## ANTI-PATTERNS

- **Don't edit** `GeneratedPluginRegistrant.ets` (regenerated by `flutter create`)
- **Don't commit** `ohos/build-profile.json5` (per-device signing, gitignored)
- **Don't add x86 native libs** — arm64-v8a only
- **Don't add ArkUI pages** unless needed outside Flutter (rare)
- **Don't skip** creating `build-profile.json5` from `关于build-profile.json5` before building

## NOTES

- 21 OHOS Flutter plugins registered (wakelock, url_launcher, media_kit, etc.)
- Cross-device continuation supported (onContinue/onWindowStageRestore)
- Background audio playback configured (delegated to Flutter's audio_service)
- Impeller rendering enabled via rawfile/buildinfo.json5
- Deep links: `bilibili://` + `https://*.bilibili.com` handled in EntryAbility
