# ohos/ — OpenHarmony Native Shell

**Overview:** Thin OHOS native layer hosting Flutter engine. ArkUI + MethodChannel bridge.

## STRUCTURE

```
ohos/
├── AppScope/                        # App-level config (bundleName, icon, label)
├── entry/                           # Single HAP entry module
│   ├── src/main/ets/
│   │   ├── entryability/            # FlutterAbility (not UIAbility)
│   │   ├── pages/                   # Single page: Index.ets (FlutterPage host + native HdsTabs bar)
│   │   └── plugins/                 # HarmonyChannel (custom) + GeneratedPluginRegistrant (auto)
│   ├── src/main/resources/          # Resources (strings, images, rawfile/buildinfo.json5)
│   ├── src/ohosTest/                # Hypium test scaffold (1 trivial assertion)
│   ├── build-profile.json5          # COMMITTED: stageMode, arm64-v8a only
│   ├── hvigorfile.ts                # stock hapTasks
│   └── oh-package.json5
├── build-profile.json5              # GITIGNORED per-device signing (copy from 关于build-profile.json5)
├── 关于build-profile.json5           # committed signing template — never commit the copy
├── hvigor/                          # Hvigor tool config (modelVersion 5.1.0)
├── hvigorconfig.ts                  # Custom: injects git metadata into DART_DEFINES + injectNativeModules
├── hvigorfile.ts                    # appTasks + flutterHvigorPlugin
└── oh-package.json5
```

## WHERE TO LOOK

| Task | Location | Notes |
|------|----------|-------|
| App entry | `entry/src/main/ets/entryability/EntryAbility.ets` | FlutterAbility, engine setup, continuation |
| OHOS↔Flutter bridge | `entry/src/main/ets/plugins/HarmonyChannel.ets` | Only custom MethodChannel ("harmonyChannel", 13 methods) |
| Add plugin (auto) | `entry/src/main/ets/plugins/GeneratedPluginRegistrant.ets` | Auto-generated, **don't edit**; regenerated by `flutter create --platforms ohos` in CI |
| Native tab bar | `entry/src/main/ets/pages/Index.ets` | HdsTabs overlay, toggled by Flutter via `useNativeTabs` AppStorage flag |
| Change resources | `entry/src/main/resources/` | Strings, media, rawfile, profiles |
| Build config (committed) | `entry/build-profile.json5` | arm64-v8a only, x86 excluded |
| Signing config (gitignored) | `build-profile.json5` | Per-device; copy from `关于build-profile.json5` before building |
| Test scaffold | `entry/src/ohosTest/` | Hypium, 1 trivial assertion |

## CONVENTIONS

- **FlutterAbility** instead of UIAbility (standard for Flutter-OHOS)
- **Single-page shell**: only `pages/Index` in main_pages.json (Flutter handles routing)
- **arm64-v8a only**: x86/x86_64 native libs explicitly excluded in `entry/build-profile.json5`
- **Stage model**: `apiType: stageMode`
- **MethodChannel** for OHOS↔Flutter communication (continuation, window state, tab switch, font weight)
- **Rawfile** for Flutter assets (flutter_assets/, libapp.so, libflutter.so)
- **Plugin registration**: `EntryAbility.configureFlutterEngine` → `GeneratedPluginRegistrant.registerWith(engine)` + `engine.getPlugins()?.add(HarmonyChannel)`
- **Cross-device continuation**: `onContinue`/`onNewWant`/`onWindowStageRestore` via `pili_continuation` want param

## ANTI-PATTERNS

- **Don't edit** `GeneratedPluginRegistrant.ets` (auto-generated; gitignored-but-tracked, edits are unpushable)
- **Don't commit** `ohos/build-profile.json5` (per-device signing, gitignored)
- **Don't add x86 native libs** — arm64-v8a only
- **Don't add ArkUI pages** unless needed outside Flutter (rare)
- **Don't skip** creating `build-profile.json5` from `关于build-profile.json5` before building
- **Don't** add custom logic to `entry/hvigorfile.ts` (stock hapTasks; custom build lives in root `hvigorconfig.ts`)

## NOTES

- 23 OHOS Flutter plugins registered (wakelock, url_launcher, media_kit, audio_service, inappwebview, etc.)
- Background audio playback configured (`backgroundModes: ["audioPlayback"]`, delegated to Flutter's audio_service)
- Impeller rendering enabled via rawfile/buildinfo.json5
- Deep links: `bilibili://` + `https://*.bilibili.com` handled in EntryAbility (module.json5 skills)
- ⚠ `EntryAbility.onWindowStageCreate` contains leftover test code (DocumentViewPicker "create download folder") — debug scaffolding, not production logic
- 6 permissions: INTERNET, READ_PASTEBOARD, GET_NETWORK_INFO, GET_WIFI_INFO, KEEP_BACKGROUND_RUNNING, VIBRATE
