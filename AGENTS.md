## OVERVIEW

Flutter-for-OpenHarmony Bilibili client (PiliPlus). Flutter/Dart handles all UI/business logic; `ohos/` is a thin native shell hosting the Flutter engine via `FlutterAbility`.

## STRUCTURE

```
./
├── lib/           # Flutter/Dart: ALL pages, models, services, widgets (core)
├── ohos/          # OHOS native shell: ArkUI host, MethodChannel bridge
├── android/ ios/ macos/ linux/ windows/  # Other platform targets
├── .github/       # CI (GitHub Actions)
├── .vscode/       # Custom build env + launch configs
├── assets/        # Static assets (fonts, images)
└── pubspec.yaml   # Flutter manifest
```
