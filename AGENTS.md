## OVERVIEW

Flutter-for-OpenHarmony Bilibili client (PiliPlus). Flutter/Dart handles all UI/business logic; `ohos/` is a thin native shell hosting the Flutter engine via `FlutterAbility`. Adaptation-only branch of upstream [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus) — no new features, only OHOS porting.
